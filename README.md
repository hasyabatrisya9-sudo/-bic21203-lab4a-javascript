## Introduction
This repository contains the exercises for Lab 4a – Client-Side Scripting using JavaScript. The lab focuses on using JavaScript to make web pages interactive.

## Lab Exercises

### Question 1: Change Text
This exercise uses JavaScript to change the text displayed on a webpage when a button is clicked.

**How to run:**
1. Open the Q1 folder.
2. Open `index.html` using a web browser.
3. Click the button to change the displayed message.

### Question 2: Check Number
This exercise checks whether the entered number is lower than, higher than, or equal to 10.

**How to run:**
1. Open the Q2 folder.
2. Open `index.html` using a web browser.
3. Enter a number and click the button to see the result.

### Question 3: Generate Numbers
This exercise uses a JavaScript loop to generate numbers from 1 to 5 and display them in a list.

**How to run:**
1. Open the Q3 folder.
2. Open `index.html` using a web browser.
3. Click the button to generate the number list.
